# Honesty Above All Else

Home station watch. Yours. No paywall.

Two halves, one watch:

- **The desk** (this app) — GitHub, mail, the wire, the ledger, reports
- **Honesty Local** (`honesty-local/`) — process list on the computer

## Honesty Local

On the home station:

1. Open the `honesty-local` folder
2. macOS: double-click `Start Honesty.command`
3. Windows: double-click `Start Honesty.bat`

Python 3 must be installed. The program reads who is running (desktop Claude, Cursor, Copilot, ChatGPT, Ollama, and the rest of the catalog) and stays on them. A browser tab is not a separate program.

## The desk

Web half. Pulls GitHub for `EverettNC` / The Christman AI Project. Records mail and the wire when those channels are seated. Keeps reports you choose to keep.

This repository is the source. It is not a subscription.
